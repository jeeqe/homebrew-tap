# homebrew-tap

Homebrew tap for [AgentBox](https://github.com/jeeqe/agentbox).

```bash
brew install jeeqe/tap/agentbox
```

The cask in `Casks/` is written by GoReleaser when a new AgentBox version is tagged.
Please don't edit it by hand. It installs the macOS binary, so on Linux use
`go install` or the install script from the main repo.
